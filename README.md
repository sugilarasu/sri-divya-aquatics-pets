# Sri Divya Aquatics & Pets — starter storefront

A responsive React + Vite storefront prototype for the Uthangarai pet and aquarium shop.

## Run locally
1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite.

## Included
- Responsive homepage, product catalogue, category filters and search
- Demo products and sample prices
- Cart saved in browser localStorage
- WhatsApp order enquiry to +91 93633 81073
- Store details, directions, delivery notice and supplied review excerpts
- Local-only product manager: add/edit/remove products and upload/change/remove product images
- Subtle entrance, floating and hover animations (respects reduced-motion settings)

## Important before publishing
This is a front-end starter, not a production-ready commerce backend. The admin demo is not secure and changes only the current browser. Uploaded images are compressed and stored in browser localStorage, so this is suitable for a prototype only. There is no real inventory, customer account, order database, payment processing or secure admin login yet.

Before accepting payments or publishing:
- Replace sample products, prices, descriptions and images with verified store information.
- Confirm store hours and delivery rules.
- Add a hosted database and secure admin authentication (for example Supabase).
- Add a real order workflow and payment provider only after merchant account setup.
- Test live-fish packaging, delivery zones and customer confirmation process.
- Configure a production domain and privacy/terms/returns policies.

The product illustrations use emoji placeholders and the hero uses an externally hosted Unsplash image.
